# Geographic data attribution

- **Country and regional context geometries:** [datasets/geo-boundaries-world-110m](https://github.com/datasets/geo-boundaries-world-110m), Natural Earth-derived data; repository metadata records ODC-PDDL-1.0 and states that the underlying Natural Earth data is public domain.
- **Bahrain island supplement:** [eFrane/admin0](https://github.com/eFrane/admin0), release line 4.0.1; repository package metadata declares CC0-1.0 and its README identifies Natural Earth v3.1 as the source.

The bundled subset is simplified for compact display. Country selection codes and labels are maintained separately in `coverage.ts` because editorial MENA coverage is not identical to a universally agreed geographic or political definition.
